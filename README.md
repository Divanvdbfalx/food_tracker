# Weight Gain Tracker (Supabase)

Next.js app for tracking bodyweight and calorie intake with Supabase.

## Features

- Separate bodyweight logging and calorie logging
- Multiple calorie entries per day with meal tags (`breakfast`, `lunch`, `snack`, `dinner`, `other`)
- Dashboard metrics for weight trend and average daily calories vs target
- Charts for daily bodyweight, 7-day rolling weight average, and summed daily calories vs target
- Mobile-friendly responsive layout for phone screens
- CSV downloads generated from Supabase data

## Setup

```bash
npm install
cp .env.local.example .env.local
npm run dev
```

Set values in `.env.local`:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`

For Vercel, add the same env vars in Project Settings -> Environment Variables.

## Supabase Setup

1. Create a Supabase project.
2. In SQL Editor, run:

```sql
create table if not exists public.bodyweight_log (
  id bigint generated by default as identity primary key,
  date date not null,
  weight_kg numeric not null,
  notes text default ''
);

create table if not exists public.calorie_log (
  id bigint generated by default as identity primary key,
  date date not null,
  time text not null,
  meal_tag text not null,
  calories integer not null,
  protein_g integer not null default 0,
  notes text default ''
);

-- If your table already exists, add the column:
alter table public.calorie_log add column if not exists protein_g integer not null default 0;
```
